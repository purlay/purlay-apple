# What can go wrong, and what holds it

For each scenario: what prevents it, what detects it, and what to do. A scenario that needs action has a runbook in
[`../runbooks/`](../runbooks/); each is short and meant to be followed step by step.

| Scenario | Prevented by | Detected by | What to do |
|---|---|---|---|
| **A secret is leaked** (committed, logged, pasted) | the pre-commit hook scans staged changes; GitHub's push protection (`.github/settings.md`); secrets only in the `release` environment, masked in logs | `security` on every CI run (gitleaks over the whole history); GitHub's secret scanning alerts | [leaked-secret.md](../runbooks/leaked-secret.md): revoke first, then clean up |
| **The signing certificate or the notarization key expires or is revoked** | expiry dates in the owner's calendar; a rehearsal before each release | the release fails at "Import the Developer ID certificate" (no valid identity) or at notarization (401, or not accepted) | [signing-credentials.md](../runbooks/signing-credentials.md) |
| **A Mac release is broken** (crashes, a regression) | main's CI on the exact commit; the rehearsal; the owner's approval of the environment | people's reports; the release's own checks (`spctl`, staple, signatures) catch a broken package, not a broken app | [rollback-mac-release.md](../runbooks/rollback-mac-release.md): a new, higher build from the last good commit. Sparkle never moves to a lower build |
| **A bad appcast** (wrong address, unsigned, wrong version) | `generate_appcast` signs it; the release checks the archive's and notes' addresses, the version and every signature before publishing | the release's "What Sparkle fetches is there" and "The feed offers this version" steps; Sparkle refuses an appcast or archive whose signature fails | [rollback-mac-release.md](../runbooks/rollback-mac-release.md#a-bad-appcast) |
| **The contract drifts from the server** | the lock pins one bundle by digest; `scripts/prepare-contract` refuses to re-pin quietly; `scripts/generate --check` | `contract-drift.yml` opens one issue weekly; the handshake refuses a server it cannot read | [contract-drift.md](../runbooks/contract-drift.md) |
| **CI is down, or the organisation is out of macOS minutes** | lanes run only when a change reaches them; the simulator only for the iOS app and the design system, and only for what needs iOS | runs queue or fail to start; GitHub's status page | [ci-outage.md](../runbooks/ci-outage.md) |
| **A flaky test** | tests wait for conditions, never for guessed times; fakes only at the edges | a lane fails on a commit that passed before; a retry warning on a run | [flaky-test.md](../runbooks/flaky-test.md): never re-run until green |
| **The disk is full**, locally or on a runner | weekly cache generations; a pull request saves a cache only when it found none; `make clean` | `No space left on device` in a build | [disk-full.md](../runbooks/disk-full.md) |
| **A vulnerability in a dependency** | no dependency beyond Sparkle ([ADR 0010](../decisions/0010-no-third-party-code-beyond-sparkle.md)); actions pinned by commit | Dependabot alerts and security updates; Sparkle's releases checked at each Mac release (TD-013) | [dependency-cve.md](../runbooks/dependency-cve.md) |
| **A compromised action** | every action pinned by full commit; `permissions: {}` and least privilege per job; signing secrets only in an approved environment; the signing job cannot write to the repository | Dependabot's update diff; the Scorecard; GitHub's advisories | [compromised-action.md](../runbooks/compromised-action.md) |
| **A force-push or deletion of main** | the `main` ruleset (no force-push, no deletion, linear history, nobody bypasses) | the push is refused | Nothing to do; if a ruleset was turned off, reapply it from `.github/rulesets/main.json` (`.github/settings.md`) and compare main with the last green CI run |
| **A release tag on an unverified commit** | the release gate refuses a commit without a successful CI run on main; release tags cannot be moved or deleted | the release fails at the gate, before any secret is used | Leave the tag (it cannot be removed and publishes nothing); merge the fix, raise the patch version, and tag the verified commit |
| **An Xcode or runner image update breaks builds** | `.github/toolchain.env` pins Xcode 27.2; every macOS job asserts it | `scripts/ci/select-xcode` fails with the Xcodes the image has | [xcode-update.md](../runbooks/xcode-update.md) |
| **The simulator runtime is missing** | the device and iOS version are named once (`.github/toolchain.env`) | `scripts/ci/simulator-destination` fails with the devices there are; a boot that does not finish in 10 minutes fails as the machine's (`scripts/ci/boot-simulator`), and is retried once | [xcode-update.md](../runbooks/xcode-update.md#the-simulator-is-missing) |
| **A Keychain or signing failure in tests** | package tests use in-memory stores; CI builds unsigned on purpose | a test that passes signed and fails unsigned; the wrong notice on an unsigned simulator build (TD-009) | [keychain-in-tests.md](../runbooks/keychain-in-tests.md) |
| **Rotating Sparkle's EdDSA key** (suspected leak, or policy) | the private key exists only in the `release` environment and the owner's offline backup | — | [rotate-sparkle-key.md](../runbooks/rotate-sparkle-key.md): the old key signs the release that carries the new public key |
| **The maintainer loses access** (account, device, Apple team) | two-factor with recovery codes; a second organisation owner; offline backups of the keys only the maintainer holds | — | [lost-maintainer-access.md](../runbooks/lost-maintainer-access.md) |
| **Installed Macs stop receiving updates** | one feed address, stated once and checked against the built app at every release | the release's feed check; an update check on a Mac with the previous version | [mac-update-feed.md](../runbooks/mac-update-feed.md) |
